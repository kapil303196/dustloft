What is System Data on a Mac?

It isn’t one thing. macOS files anything it can’t categorise under that label — caches, containers, virtual machine disks, downloaded models, old device backups — then gives you no way to look inside. That’s why it grows to 100 GB and nobody can say why.

The part most cleaners get wrong

Freeing space is easy. Not destroying something irreplaceable while you do it is the hard part. Attic sorts everything it finds into three tiers, and the tier decides how much friction stands between you and the delete button.

Regenerable

Caches, build output, dependencies, Docker images. Comes back on its own. This is what one-click Quick Clean touches, and nothing else.

Needs admin

Safe to remove, but macOS asks for your password. Every item like this is batched into a single prompt rather than one per file.

Permanent

Gone forever. Never bulk-selected, never included in Quick Clean, and gated behind a separate confirmation you have to tick yourself.

What Attic refuses to do

  • Delete a .git directory. Ever. It offers git gc instead, and flags in red any repository whose history exists nowhere but your disk.
  • Touch Dropbox, iCloud Drive or any synced folder. A local delete there propagates to every other device. Not overridable.
  • Remove Docker volumes. Images and stopped containers, yes. The volumes holding your databases, never.
  • Claim it can reclaim “purgeable” space. No third-party app reliably can. Cleaners that promise it are overpromising.

The near-miss that shaped the rules

Every safety rule above came from an actual cleanup, not a checklist. This one came closest to being a disaster.

During the manual cleanup this app was built from, one project’s .git folder was 2.2 GB. It had a GitHub remote configured, so deleting it looked obviously safe.

Running git ls-remote first told a different story. The remote authenticated successfully and returned zero refs. Nothing had ever been pushed. That local .git was the only copy of the project’s history that existed anywhere.

A repository with a remote configured looks backed up. It isn’t, until something has actually been pushed.

Attic now runs that check for you, and never offers to delete a .git folder at all.

Nothing is removed until you’ve seen it

Every item is listed with its full path and real size. Untick anything you want to keep — the total follows along, and permanent items need one more confirmation before the button works.

Install

One command. It fetches the latest release, installs it, and opens it.

curl -fsSL https://raw.githubusercontent.com/kapil303196/attic/main/install-online.sh | bash

Prefer a disk image? Download the DMG. Note that macOS shows a security warning for apps that aren’t notarised — the one-line install avoids it, because quarantine is applied to browser downloads and not to curl.

Is it safe to run?

The source is public and the safety rules are enforced in code and covered by tests — including that synced folders can never be offered for deletion, and that a repository with no remote refs is reported as the only copy. Nothing is deleted without a review screen.

Why does it ask for Full Disk Access?

Without it macOS hides the Trash, app containers and device backups, so sizes come out far lower than reality — and it asks separately for Desktop, Downloads and Documents. Attic asks once, up front, and explains why. macOS applies the permission only to a freshly launched app, so it restarts itself once.

Why the “unidentified developer” warning?

Notarisation requires a paid Apple Developer membership. The build is signed but not notarised. The one-line installer sidesteps the warning legitimately; from the DMG, use System Settings → Privacy & Security → Open Anyway.

Does it work on Intel Macs?

Yes. Every release is a universal binary built in CI and verified with lipo to contain both architectures.

What does it cost?

Nothing. MIT licensed, no telemetry, no account, no upsell.

Will it delete something I need?

Not without showing you first. Everything is listed with its full path and real size, and you untick anything you want to keep. Items that cannot be recovered are never bulk-selected and need a separate confirmation. Quick Clean only ever touches things that rebuild themselves.

Why is my System Data so large?

Because macOS files everything it cannot categorise under that one label — caches, app containers, virtual machine disks, downloaded models, old device backups, local snapshots. It grows quietly and there is no built-in way to see inside it. That is the specific problem Attic was built to solve.

Does emptying the Trash actually free the space?

Usually, but not always. Root-owned items left by uninstalled apps often refuse to delete and sit there indefinitely. Attic spots those and removes them under a single administrator prompt.

Can it clean an external drive?

Not yet. Scanning is scoped to your home folder and system locations on the startup disk.

How is it different from CleanMyMac?

It is free, open source, and has no subscription. It also declines to do several things commercial cleaners advertise: it will not claim to reclaim purgeable space, will not delete a .git directory, and will not touch a cloud-synced folder. The trade is fewer promises and no surprises.
