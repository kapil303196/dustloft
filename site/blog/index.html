How these numbers were measured

Three capacities for the same disk appear across these guides, and they are the same disk measured three ways. 512 GB is the marketing capacity, the figure the machine is sold as. 494 GB is what is left once the drive is formatted, which is why a Docker disk image reporting 494 GB was reporting the size of the whole drive. 460 GiB is the same 494 GB counted in binary units rather than decimal ones, and it is the figure df -h /System/Volumes/Data prints, because that is the volume your files live on.

Every size quoted is allocated size, as reported by du. None of them is apparent size, as reported by ls. For an ordinary file the two agree; for a sparse file they can differ by hundreds of gigabytes, so only the allocated figure describes space the disk has actually given up.

Common questions

What is System Data on a Mac?

System Data is not a category of file. It is the bucket macOS uses for everything it cannot file anywhere else — caches, app containers, virtual machine disks, downloaded AI models, old device backups and local snapshots. Nothing prunes it automatically and macOS provides no way to look inside it.

How much space can clearing System Data free?

It depends entirely on what is inside it, so measure before assuming. On the one 512 GB MacBook Pro these guides are written from, working through it took the machine from 20 GB free to 215 GB free without deleting a single irreplaceable file. The 220 GB labelled System Data there turned out to be eight identifiable things, the largest being 92 GB of messaging media and 46 GB of dependency folders.

What is the best free alternative to CleanMyMac?

There is no single replacement. GrandPerspective and OmniDiskSweeper show what fills a disk, AppCleaner and Pearcleaner remove app leftovers, OnyX handles system maintenance, and Dustloft explains and reclaims System Data. All are free. There is a direct comparison with CleanMyMac, and a wider round-up of the free tools.
